## 需求点

用户诉求（原话大意）：

> 微信小程序推送消息授权是需要用户手动点击吗？还是可以加引导提示？如果可以的话，能不能加那种提示？

用户决策：**方案 A（状态徽章+引导条）+ 方案 B（关键节点说明弹窗）**，并顺带完成 006 收尾（home.controller SQL 清理 + 006 验收补录）。

背景约束（007 已确立）：

- `wx.requestSubscribeMessage` **必须由用户点击事件的同步调用链触发**（微信平台硬约束，否则报 `can only be invoked by user TAP gesture`），纯自动弹窗不可能。
- 一次性订阅：每授权 1 次 = 每模板 1 条额度，需要**长期入口 + 节点引导**，不是一次性动作。
- 007 现状问题：登录/注册/消息中心入口**无任何提示直接弹授权**，用户不知所云，体验差。

## 关键决策

- **授权只从显式入口触发**：横幅「立即开启」按钮、说明弹窗「立即开启」按钮——用户明确知道点了会收到什么。移除一切无提示自动弹窗。
- **静默状态感知**：`wx.getSetting({withSubscriptions:true})` 查询不需要点击；总开关关闭 → 引导去 `wx.openSetting`（仍由用户 tap 确认）。
- **演示模式兜底**：`SUBSCRIBE_TMPL_IDS` 为空（默认，零资质）时引导 UI 照常可见，点击提示「演示模式，请在 config.js 配置模板 ID」——保证无资质也能演示交互；授权成功即写 storage 不再骚扰。
- **频控**：横幅授权成功后隐藏（storage）；说明弹窗每节点 7 天最多弹 1 次（storage 时间戳）。
- **一次性额度明示**：授权成功 toast 文案「已开启，可收到 1 条通知」，避免用户误以为永久开启。

## 使用说明

- **横幅（方案 A）**：「我的」/消息中心顶部，未授权时常驻；点「立即开启」→ 静默查总开关：已关闭 → 弹「去设置」引导 `wx.openSetting`；开启 → `requestSubscribeMessage`。授权成功 toast 明示「本模板可收到 1 条」并写 storage，横幅不再出现。
- **说明弹窗（方案 B）**：下单成功 / 入驻提交成功节点，居中弹窗讲清价值与一次性额度；点遮罩或「暂不开启」关闭（不写频控时间戳外的打扰）；每节点 7 天最多弹 1 次，已授权过（`isAccepted`）不再弹。下单节点弹窗关闭后才继续跳订单详情。
- **演示模式**：`config.js` 的 `SUBSCRIBE_TMPL_IDS` 为空（默认）时，引导 UI 照常可见、可点击（无资质也能演示交互），点击提示「演示模式：请在 config.js 配置模板 ID」；填入真实模板 ID 后自动进入真实授权流程（配合 007 的服务端配置）。
