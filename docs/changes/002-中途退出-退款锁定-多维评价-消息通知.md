## 需求点

- 「中途」从**开工（working）**起算：预约时间（expect_at）前未开工一律可全额退款；接单人须按时上门且要有消息通知。
- 退款政策**下单时锁定**：约定不支持中途退款则开工后不可退。
- hourly 中途退出取整：**不足半小时按半小时**（40 分钟 = 1 小时 × 时薪）。
- 评价：**多维度 + 双向互评**；评分低于阈值**限制接单/发单一段时间**。

## 关键决策

- **退款决策表**（cancel 接口内唯一入口）：
  - 开工前取消 → 一律全额退；
  - working + flexible 客户取消 → 按进度退（hourly 按「不足半小时按半小时」公式；fixed 实收 0，全退）；
  - working + strict 客户取消 → **409**（下单已锁定，开工后不可退）；
  - 运营手动退款 → 带 `{amount, reason}`。
- `refund_policy`（flexible/strict）与 `billing_type`（fixed/hourly）**下单锁定不可改**。
- 低分惩罚阈值 env 可调：`RESTRICT_MIN_RATING=3.0 / RESTRICT_WINDOW=5 / RESTRICT_DAYS=7`；拦截 accept/dispatch/下单 403，到期自动解。
